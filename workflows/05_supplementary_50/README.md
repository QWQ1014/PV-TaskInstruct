# Supplementary 50-item evaluation

`gold-blind` creates a blinded review CSV and a separate key from human-gold answers plus base/tuned outputs. `gold-score` calculates metrics from those inputs. Run `python run.py gold-blind --help` or `python run.py gold-score --help` at the repository root. The supplied `data/evaluation/` directory contains the 50-item gold set, aligned outputs, and reported summaries.
